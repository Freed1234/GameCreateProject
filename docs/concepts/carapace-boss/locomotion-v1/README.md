# 황금갑각 그림자·걷기 모션 · 2026-11-20

[동작 확인 영상](CarapaceMotion.mp4): 약 **25초, 1280×720, 30fps, 무음**. 실제 보스 컴포넌트를 사용한 통제된 Unity 시연입니다. 이동·정지·세 공격을 보기 쉽게 일반 적과 주변 장애물을 숨기고, 테스트 대상으로 이동과 공격을 지시했습니다. 자연 플레이 영상이나 밸런스 검증 영상은 아닙니다. 이 시연 설정은 원래 게임 씬에 저장하지 않았습니다.

## 적용 내용

- 기존 황금 갑각·청색 몸체 디자인에 맞춘 걷기 8프레임, 대기 호흡 4프레임을 추가했습니다.
- 원본은 `Assets/Art/BossPreview/Locomotion.png`, 런타임 프레임은 `Assets/Resources/CarapaceDemo/Walk`와 `Idle`입니다. imagegen으로 제작한 시트를 Unity에서 분리했습니다.
- 기존과 같은 PPU 80·Point 필터·무압축, 발 기준 피벗을 사용합니다. 한 시트의 배율을 고정해 프레임마다 몸 크기를 재정규화하지 않습니다.
- `CarapaceLocomotion`은 실제 이동 거리 1.28유닛마다 걷기 한 주기를 재생합니다. 이동속도 1.6에서 약 0.8초입니다. 정지 시 1.2초 호흡 루프로 바뀝니다.
- 기존 좌우 반전을 유지하고, 차징·공격·회복 단계에는 몸 스프라이트를 덮어쓰지 않습니다. 루트·충돌체·공격 범위와 전투 수치는 변경하지 않습니다.
- 기존 `CharacterGroundShadow`에 생성 시 설정을 전달하는 `Configure`를 추가했습니다. 기존 타원 스프라이트·지면 머티리얼을 그대로 사용하며, 2.2×0.65유닛·알파 0.28·발 위치 고정입니다. 그림자는 WorldGround에 표시되고 보스 제거 시 정리됩니다.

## 증강 보류

사용자 요청에 따라 실제 게임 씬의 `AugmentSystem`을 비활성화하고, `BossDirector.offerAugmentOnKill`을 false로 설정했습니다. 선택 창은 비활성 상태입니다. 기존 코드·카드 에셋은 보존하며 수련·재능 수정이나 PlayerStats 추가는 하지 않았습니다. 처치 경험치와 마지막 보스 클리어 처리는 유지합니다.

현재 정책에 맞춰 `EnemyLifetimeCheck`와 `CarapaceNaturalPlayCheck`는 증강 창 없이 처치 후 전투가 계속되는 경로를 검사합니다. 이전 증강 선택 영상·로그는 당시 상태의 기록입니다.
