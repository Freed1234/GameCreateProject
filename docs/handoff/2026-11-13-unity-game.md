- 단검을 든 미전직 상태에서 시작합니다. 2레벨에 궁수를 확정하면 궁수 자동 평타와 Z 부채꼴 연사, X 화살비, C 크리스탈 애로우, Shift 회피 사격을 사용합니다. 기존 1차 Z 단발 관통화살은 비활성화했고 30레벨 전직은 보류했습니다.

- 미전직과 궁수에 4방향 모션이 있습니다. 일반 적은 같은 능력치로 슬라임·버섯 중 하나와 색상을 무작위로 선택합니다.

- 나무 테마 HUD와 시작 메뉴, 스킬·대쉬 키 변경, 캐릭터창 누르기·토글 설정을 지원합니다. 세부 변경 내역은 프로젝트 루트 README.md에 있습니다.
