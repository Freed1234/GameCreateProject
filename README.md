## Ver 0.6 (2026.10.19)

### 게임오버 후 재시작
- 게임오버 상태에서 R키를 누르면 현재 씬을 다시 시작하도록 구현.
- 재시작 시 체력·레벨·경험치·직업·대쉬 충전을 초기 상태로 복구.
- 게임오버 화면에 R키 재시작 안내 표시.
- 기존 대쉬 중 적 접촉 피해 방지 기능 유지.

### 전체화면 및 창모드 전환
- F11키로 전체화면과 창모드를 전환하는 기능 추가.
- 전체화면은 테두리 없는 전체화면 방식 사용.
- 창모드 기본 해상도는 1280×720으로 설정.
- Inspector에서 전환 키와 창모드 해상도 변경 가능.
- 게임오버 및 전직 선택 중에도 화면 모드 전환 가능.
- Unity 에디터에서는 전환하지 않으며 빌드한 실행파일에서 사용.

### 장애물 랜덤 생성 좌표값 수정
- 기존 랜덤 장애물이 배치될 좌표의 x축과 y축을 일관적이지 않도록 수정.

### 스택형 대쉬
- Shift키로 대쉬 사용.
- 시작 시 대쉬 3개 보유, 최대 3개까지 충전.
- 대쉬 사용 시 충전 1개 소비.
- 3초마다 대쉬 1개씩 순차 충전.
- 충전 중 대쉬를 사용해도 진행 중인 충전 시간 유지.
- 이동 방향으로 대쉬하며, 정지 상태에서는 마지막 이동 방향으로 사용.
- 대쉬 중 적을 관통하고 적 접촉 피해를 받지 않도록 처리.
- 돌과 나무의 장애물 충돌은 유지.
- 게임 일시정지 중에는 대쉬 사용과 충전도 정지.
- 화면에 남은 대쉬 개수와 다음 충전까지의 시간 표시.

### 대쉬 사운드
- 대쉬가 실제로 발동할 때 효과음을 재생하는 기능 추가.
- Inspector에서 대쉬 음원과 볼륨 설정 가능.
- 실제 음원 연결 및 재생 확인은 미완료.

### 캐릭터 좌우 방향 전환
- A키 또는 왼쪽 방향키 입력 시 왼쪽을 바라보도록 처리.
- D키 또는 오른쪽 방향키 입력 시 오른쪽을 바라보도록 처리.
- 위아래 이동 및 정지 상태에서는 마지막 좌우 방향 유지.
- 대기 이미지와 공격 이미지에 동일하게 좌우 반전 적용.
- 원본 이미지가 바라보는 방향을 Inspector에서 설정 가능.
- 교체 코드 작성 완료, 실제 프로젝트 적용은 미확인.

### 궁수 화살 이미지 적용 준비
- 평타와 관통 스킬이 같은 투사체 프리팹을 사용하는 구조 확인.
- 공통 프리팹에 화살 이미지를 연결하는 방법 안내.
- 이미지 색상, 크기 및 발사 방향에 맞춘 회전 설정 안내.
- 실제 화살 이미지 연결 및 표시 확인은 미완료.



## Ver 0.5 (2026.10.07)

### 레벨 및 경험치
- 적 처치 시 경험치 1 획득.
- 1레벨 → 2레벨에 필요한 경험치: 5.
- 2레벨 이후 레벨업에 필요한 경험치: 매번 10.
- 화면 하단에 레벨과 경험치바 표시.
- 레벨업 후 남은 경험치는 다음 레벨로 이월.

### 전직
- 2레벨 달성 시 전직 선택창 표시.
- 전직 선택 중 게임 일시정지.
- 궁수 선택 가능.
- 전사는 준비 중으로 표시하며 선택 불가.
- 선택창을 닫은 경우 하단 버튼으로 다시 열기 가능.

### 직업별 공격
- 미전직: 짧은 사거리의 부채꼴 기본공격.
- 궁수 전직 후: 비관통 투사체 평타와 관통 스킬 사용.
- 평타는 0.5초 간격으로 자동 발사.
- 관통 스킬은 Z키로 사용하며 쿨타임은 5초.
- 관통탄은 적을 관통하며 카메라 밖으로 나가면 제거.
- 돌과 나무는 투사체를 차단.
- 직업별 공격 목록을 설정하여 공격 방식을 전환하는 구조 추가.

## Ver 0.3

### 청크 기반 맵 로딩
- 플레이어가 있는 청크와 주변 8개 청크를 불러오도록 구현.
- 이동에 따라 새로운 청크를 생성하고 멀어진 청크는 제거.
- 카메라에 보이는 영역이 청크 한 칸보다 작도록 크기 조절.

### 돌·나무 랜덤 배치
- 청크 안의 지정된 위치마다 나무·돌·없음 중 하나를 랜덤으로 선택.
- 생성 확률: 나무 30%, 돌 30%, 없음 40%.

### 장애물 충돌
- 돌과 나무의 충돌 영역을 이미지 형태에 맞게 조절.
- 나무의 잎 부분은 통과할 수 있고, 기둥 부분은 통과할 수 없도록 설정.
- 플레이어와 적이 장애물을 통과하지 못하도록 처리.

### 적의 장애물 우회 길찾기
- 적이 장애물에 막혀 멈추지 않고 우회하여 플레이어에게 접근하도록 구현.
- 여러 적이 경로 정보를 공유하도록 구성.
- 플레이어가 장애물에 붙었을 때 발생하던 과도한 경로 탐색 횟수를 줄여 최적화.

### 자동 공격의 가까운 적 우선순위 강화
- 공격 방향을 결정할 때 가까운 적에 더 큰 가중치를 부여.
- 가까운 적을 우선하는 정도를 설정값으로 조절할 수 있도록 구현.

### 맵, 장애물 이미지와 표시 순서
- 나무 이미지를 본체와 그림자로 분리.
- 나무의 잎 부분이 캐릭터 앞에 표시되도록 구성.
- 그림자는 캐릭터 아래에, 나무 본체는 위에 표시하도록 구성.
- 해당 버전 기준으로 실제 프로젝트 적용은 미완료.
