## Ver 0.9 (2026.11.10)

### 궁수 1차 전직 스킬 개편
- 기존 2차 궁수 스킬 전체를 1차 전직으로 이동.
- 2레벨에서 궁수를 선택하면 Z 부채꼴 연사·X 화살비·C 크리스탈 애로우·Shift 회피 사격 사용 가능.
- 기존 1차 Z 단발 관통화살은 게임에서 제거.
- 궁수 자동 평타와 기존 스킬 피해량·쿨타임·화살 수·이미지·효과음 설정 유지.
- 30레벨 전직 확인창과 재진입 버튼 제거. 새로운 2차 전직은 보류.
- 전직을 보류하면 미전직 공격과 외형 유지. 전사는 준비 중으로 선택 불가.
- 전직 선택창 설명과 HUD를 새 스킬 구성에 맞게 변경.
- 캐릭터 정보창에 ‘1차 궁수’ 표시.
- 미전직 상태에서는 Z/X/C 잠금 표시, 궁수 확정 시 활성화.
- 기존 관통화살과 새 Z스킬이 중복 발사되지 않도록 공격 관리 정리.

### 다수 타격 우선 스킬 조준
- 궁수 Z/X/C가 가까운 적 한 명보다 여러 적을 맞힐 수 있는 방향과 위치를 우선 선택하도록 변경.
- 예상 피격 적 수를 우선하며, 같은 적은 인원수에 중복 계산하지 않도록 처리.
- 예상 피격 인원수가 같으면 가까운 적 무리를 우선 선택.
- Z는 실제 개별 화살 경로와 장애물 차단을 반영하여 조준.
- X는 적 사이의 빈 공간도 후보에 포함하여 더 많은 적이 들어오는 장판 중심 선택.
- C는 최초 충돌할 적과 해당 위치의 폭발 범위를 기준으로 조준.
- 조준은 스킬 발동 순간 한 번 결정하며, Z 연사 중 방향 고정.
- Inspector의 Prefer Multiple Targets를 끄면 기존 최근접 조준 사용 가능.
- 자동 평타와 이동 반대 방향 회피 사격, 기존 공격 수치와 분열 규칙 유지.

### 플레이어 4방향 모션
- 미전직·궁수 캐릭터에 상하좌우 숨쉬기·걷기·공격·피격 모션 추가.
- 외형별로 방향마다 숨쉬기 2장·걷기 4장·공격 3장·피격 2장, 총 44프레임 구성.
- 기본 재생 속도는 숨쉬기 2fps, 걷기 8fps로 설정.
- 공격 모션은 0.15초, 피격 모션은 0.16초를 기본으로 사용.
- 대각선 이동은 좌우 방향을 우선 표시하고, 정지 시 마지막 이동 방향 유지.
- 이동 중 공격하면 실제 공격 방향을 잠깐 바라본 뒤 이동 모션으로 복귀.
- 모션 때문에 이동이나 실제 공격 발사가 지연되지 않도록 처리.
- 연사 중에는 매 발마다 모션을 처음부터 재생하지 않도록 보완.
- 대쉬 중 회피 사격으로 캐릭터가 반대 방향을 바라보지 않도록 처리.
- 실제 체력이 감소했을 때만 피격 모션을 재생하며 기존 무적 깜빡임 유지.
- 일시정지 중 모션 정지, 재시작 시 상태 초기화.

### 미전직 외형과 전직 전환
- 게임 시작 시 금발·초록 목도리·밝은 상의·단검을 든 미전직 외형 사용.
- 미전직 공격에 베기·후속 동작·복귀 모션 적용.
- 단검 모션과 기존 부채꼴 공격의 실제 방향을 일치시키도록 연결.
- 궁수 전직 확정 시 기존 궁수 외형과 모션으로 전환.
- 전직 선택을 보류하면 미전직 외형 유지.
- 재시작하면 미전직 외형으로 초기화.
- 프레임이 누락되면 대기 이미지 또는 기본 이미지로 대체.

### 슬라임·버섯 랜덤 외형
- 일반 적 생성 시 슬라임과 버섯을 각각 50% 확률로 선택.
- 종류별 5색을 동일 확률로 선택하며, 전체 10개 외형은 각각 10% 확률로 등장.
- 외형과 색상은 생성 시 한 번 결정하고 생존 중 유지.
- 슬라임 16프레임·버섯 8프레임 이동 모션 적용, 기본 10fps 반복.
- 실제 좌우 이동에 따라 이미지를 반전하고 위아래 이동 시 마지막 좌우 방향 유지.
- 정지·기절 중 현재 프레임 유지, 일시정지 중 모션 정지.
- 외형과 관계없이 기존 체력·이동 속도·접촉 피해·경험치·충돌 판정 유지.
- 기존 적 생성·거리 기반 제거·장애물 우회 길찾기 유지.

### 나무 테마 UI
- HUD·설정창·일시정지창·게임오버창의 패널과 버튼에 나무 테마 적용.
- 체력·레벨·경험치·생존 시간·처치 수 표시.
- 체력 감소량이 잠시 남았다가 줄어드는 잔상 연출 추가.
- 경험치바는 화면 하단에 배치.
- 우측 하단 스킬바에 Z/X/C 쿨타임과 사용 가능 상태 표시.
- Shift 슬롯에 대쉬 충전 개수와 충전 진행률 표시.
- 충전 중에도 남은 대쉬가 있으면 사용 가능한 상태로 표시.
- 전직 선택창에 일러스트와 선택 강조 표시 적용.

### 시작 메뉴 및 키 설정
- 게임 시작·설정·종료가 가능한 시작 메뉴 추가.
- 게임 중 메뉴로 돌아가기와 새 게임 시작 연결.
- 대쉬·Z/X/C·캐릭터창 키 변경 및 저장 기능 추가.
- 같은 키를 중복 지정하면 기존 키 배정과 교환.
- 기본 키 복원 기능과 변경한 키의 HUD 표시 추가.
- 키 등록 중 게임 입력을 차단하고 Esc로 등록 취소 가능.
- 캐릭터창을 누르는 동안 열기 또는 한 번 눌러 열고 닫기 중 선택 가능.
- 기존 음량·전체화면 설정과 R키 재시작 유지.

### 경험치 드랍과 흡수
- 적 처치 즉시 경험치를 지급하던 방식을 바닥 구슬 드랍으로 변경.
- 일반 적 기본 경험치는 1이며 Inspector에서 적별 드랍량 조절 가능.
- 처치 수는 적 사망 즉시 증가하고, 경험치는 구슬이 플레이어에게 도착했을 때 획득.
- 기본 반경 2 안에 접근하면 플레이어를 향해 가속하며 흡수.
- 흡수가 시작된 구슬은 멀어지거나 대쉬해도 계속 추적.
- 빠르게 지나간 이동 구간도 검사하여 구슬을 놓치지 않도록 처리.
- 구슬은 돌·나무·적의 충돌에 막히지 않도록 구성.
- 거리 기반 적 제거에서는 경험치를 드랍하지 않도록 처리.
- 1→2레벨 요구 경험치 5, 이후 요구 경험치 10과 남은 경험치 이월 유지.

### 경험치 보존 및 누적 관리
- 가까운 흡수 전 구슬은 하나로 합치고 경험치 총량 유지.
- 흡수 중인 구슬은 합치기 대상에서 제외.
- 멀어진 청크의 경험치는 데이터로 보존하고 재방문 시 다시 표시.
- 멀어졌다는 이유로 경험치를 삭제하거나 자동 지급하지 않도록 처리.
- 표시 오브젝트 재사용과 근거리 공간 검색으로 누적 부하 감소.
- 일시정지·전직 선택 중 흡수와 획득 정지, 사망 후 획득 차단.
- 재시작·메뉴 복귀·새 게임에서는 이전 판의 경험치 초기화.

### 경험치 구슬 및 레벨업 연출
- 경험치 구슬을 흰색 중심·연한 연두색 가장자리의 픽셀 외형으로 변경.
- 경험치량 1~4 / 5~19 / 20 이상에 따라 본체 폭을 0.26 / 0.32 / 0.40으로 구분.
- 작은 구슬의 크기를 키워 바닥에서 쉽게 구분되도록 개선.
- 구슬 주변에 4프레임 십자 반짝임 추가.
- 일반 흡수와 전체 회수 자석에 같은 외형 적용.
- 레벨업 시 현재 캐릭터의 연두빛 발광·발밑 링·픽셀 입자 연출 추가.
- 한 번에 여러 레벨이 오르거나 연속 상승하면 효과를 합쳐 중복 발광 방지.
- 일시정지·전직창에서는 연출 정지, 사망·재시작 시 정리.
- Inspector에서 구슬 크기와 효과의 색상·크기·재생 시간 조절 가능.

### 탐험형 상자
- 새로운 청크 탐험 시 기본 40% 확률로 상자를 최대 1개 배치.
- 같은 지역에 머무르는 시간에 따른 추가 생성 없음.
- 장애물과 겹치지 않고 접근 가능한 위치에 배치.
- 가까이 접근하면 자동 개봉하고 보급품 1개 표시.
- 개봉만으로 아이템 효과가 즉시 적용되지 않도록 처리.
- 청크 재방문 시 상자 위치·보상 종류·개봉·획득 상태 유지.
- 열린 상자 외형을 남겨 방문한 장소를 구분할 수 있도록 구성.
- 일시정지·전직창에서는 개봉과 획득 정지, 새 게임에서는 상태 초기화.

### 상자 보급품과 흡수
- 회복 물약: 기본 확률 50%, 체력 3 회복, 최대 체력 초과 불가.
- 자석: 기본 확률 20%, 현재 판에 남아 있는 대기 경험치 전체 회수 시작.
- 대쉬 충전: 기본 확률 30%, 대쉬 충전 1개 추가, 최대 충전 유지.
- 보급품에 가까이 접근하면 경험치처럼 플레이어에게 끌려오도록 처리.
- 아이템이 플레이어에게 도착했을 때 효과를 한 번만 적용.
- 최대 체력·최대 충전·회수할 경험치가 없는 경우 아이템 유지.
- 흡수 도중 사용할 수 없는 상태가 되면 원래 상자 위치로 복귀.
- 대쉬·청크 이동 중에도 보급품 추적 유지.
- 대쉬 충전 아이템은 대쉬나 회피 사격을 자동 실행하지 않음.
- 획득 시 실제 회복량·경험치 회수·대쉬 충전 알림 표시.

### 전체 경험치 회수 자석
- 현재 화면뿐 아니라 멀어진 청크에 보관된 대기 경험치도 회수.
- 자석 획득 순간의 대기 경험치만 대상으로 확정.
- 이미 흡수 중인 구슬은 기존 추적을 유지하고 중복 회수 방지.
- 자석 획득 이후 새로 드랍된 경험치는 일반 흡수 규칙 적용.
- 원거리 경험치는 화면 가장자리에서 들어오는 묶음 연출로 전환.
- 원거리 묶음 연출은 동시에 최대 16개로 제한하고 나머지는 대기 데이터로 보관.
- 경험치는 연출이 도착했을 때 지급하며 전체 경험치량 보존.
- 자석은 상자 보급품이나 다른 자석을 끌어오지 않도록 처리.

### 캐릭터 발밑 그림자
- 플레이어와 슬라임·버섯 적에 반투명 픽셀 타원 그림자 추가.
- 모션 전환·좌우 반전 중에도 발 기준점과 그림자 크기 유지.
- 미전직에서 궁수로 전직할 때도 같은 발밑 그림자 유지.
- 캐릭터 피격 깜빡임과 독립적으로 그림자 표시.
- 적 비활성화·처치·거리 제거·재시작 시 그림자 숨김 및 정리.
- Inspector에서 그림자의 폭·높이·위치·색상·진하기 조절 가능.
- 그림자 적용 파일과 설정 도구 제작 완료, 원본 프로젝트 적용은 별도 진행.

### 적용 도구 및 개발 범위
- 모션·적 외형·경험치·상자·궁수 스킬·그림자 전용 설정 메뉴 제공.
- 기존 이미지와 .meta 참조를 보존하는 추가·교체 파일 형태로 전달.
- 신전·스탯 강화·인벤토리·중간보스·새 원거리 적은 이번 구현 범위에서 제외.
- 3·4차 전직과 증강 기능은 활성화하지 않음.


## Ver 0.8 (2026.11.03)

### 궁수 2차 전직
- 2레벨 직업 선택을 1차 전직으로 표시.
- 궁수 30레벨 달성 시 2차 전직 확인창 표시.
- 전직 선택 중 게임 일시정지.
- ‘나중에’ 선택 시 기존 스킬을 유지하고 재진입 버튼 제공.
- 2차 전직 확정 시 기존 Z 관통 스킬을 끄고 새 Z/X/C 스킬과 회피 사격 활성화.
- 기존 자동 평타 유지.
- 캐릭터 정보창에 ‘2차 궁수’ 표시.

### Z — 부채꼴 연사
- 발동 순간 조준 방향을 고정하고 관통 화살 12발을 순서대로 발사.
- 전체 발사 각도 50도, 발사 간격 0.035초.
- 기본 피해량은 발당 6, 쿨타임은 6초.
- 화살은 돌과 나무에 막히도록 처리.
- 실제 화살 발사마다 단발 효과음을 중첩 재생하는 기능 추가.
- Inspector에서 단발 음원과 볼륨 설정 가능.

### X — 화살비
- 가까운 적의 발동 당시 위치에 원형 장판 생성.
- 적이 없으면 마지막 이동 방향의 3 거리 앞에 생성.
- 장판 위치는 발동 후 고정.
- 기본 지속 시간 2.5초, 반경 2.5.
- 0.25초마다 범위 내 적에게 피해 2 적용.
- 쿨타임은 8초.

### C — 크리스탈 애로우
- 장애물을 통과하는 거대 얼음 화살 발사.
- 적 명중 시 직격 피해와 범위 폭발·기절 적용.
- 기본 직격 피해 25, 폭발 피해 12, 폭발 반경 3, 기절 1.5초.
- 폭발 후 화살 8발이 퍼지고, 명중 시 각각 3발로 분열.
- 다음 명중 시 다시 각각 3발로 분열하며 최대 3단계에서 종료.
- 기본 분열탄 피해는 5, 쿨타임은 20초.
- 분열탄은 장애물에 막히며, 같은 분열 경로에서 앞 단계가 맞힌 적을 다시 타격하지 않도록 처리.

### Shift — 회피 사격
- 2차 전직 이후 대쉬 시작 지점에서 이동 반대 방향으로 화살 3발 발사.
- 기본 전체 발사 각도 24도, 발당 피해 6.
- 회피 사격 화살은 적을 관통하지 않음.
- 이동 방향 대쉬와 정지 시 마지막 이동 방향 사용 유지.
- 최대 3개 충전, 3초마다 1개 회복하는 기존 대쉬 충전 공유.
- 기존 대쉬 거리·효과음·적 관통·접촉 피해 방지 유지.
- 대쉬 한 번에 사격이 한 번만 발생하도록 연결.

### 스킬 화살 크기 조절
- Z 연사와 C 최초 거대 화살은 Arrow Scale로 크기 조절.
- X 화살비에 Arrow Scale 설정 추가.
- C 첫 분열탄에 Scatter Scale 설정 추가.
- C 후속 분열탄은 Split Scale Falloff 비율을 단계마다 곱해 크기 조절.
- 이미지 크기 변경 시 피해량과 타격 판정 범위는 유지.

### HUD 및 동작 보완
- 2차 전직 후 HUD의 Z/X/C 슬롯을 새 스킬과 연결.
- Shift 슬롯의 기존 충전 표시 유지.
- 빠른 스킬 화살이 적이나 장애물을 건너뛰지 않도록 이동 구간 충돌 검사 보완.
- 사망 시 진행 중인 연사·화살비를 중단하고 남은 스킬 투사체 정리.
- 씬 재시작 시 전직·스킬 상태 초기화.
- 30레벨을 기다리지 않고 2차 전직창을 열 수 있는 테스트 메뉴 제공.
- 3·4차 전직, 보스, 스탯·증강 기능은 이번 활성화 범위에서 제외.
