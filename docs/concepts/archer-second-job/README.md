## 비교 포인트

- **Z1:** 생존 중인 한 적에게 집중하고 처치 후 전환합니다. **Z2:** 가까운 최대 세 적을 순차 조준합니다. **Z3:** 세 발 단위 점사 후 표적을 다시 선택합니다.
- Z는 0.8~2.8초 동안 발사하며, 매 발마다 현재 표적 위치를 향한 정확한 방향을 계산합니다. 발사된 화살은 직진하고 실제 이동 구간과 적의 충돌을 검사합니다. 움직이는 적을 빗맞힐 수 있으며 유도탄이나 명중 보장 공격이 아닙니다.
- **X1:** 고정 중심 흡인. **X2:** 전진 중심 흡인. **X3:** 두 회오리가 각각 흡인하다 합쳐져 마지막 타격을 냅니다.
- **C1:** 굵고 큰 화살. **C2:** 가는 중심 화살과 나선 기류. **C3:** 화살 뒤에 넓은 돌풍이 따라가며 밀치기가 늦게 발생합니다.
- **Shift1:** 전방 쐐기. **Shift2:** 몸 주변 나선. **Shift3:** 도착 후 경로 폭발. 첫 두 안은 이동 중, 세 번째 안은 이동 완료 후 적을 밀칩니다.
- 체력바는 타격을 알아보기 위한 시안용 값입니다. X/C/Shift의 이동과 타격은 연출 비교를 위한 시간 기반 모형이며 실제 Unity 물리 검증은 아닙니다.

Pillow가 설치된 Python에서 `generate.py`를 실행하면 모든 GIF와 `overview.png`, `verification.json`을 재생성합니다. 한글 글꼴은 Windows 맑은 고딕을 사용합니다.

- Z 각 후보의 표적 전환, 정확한 발사 방향, 적이 없을 때 발사 억제, 표적 공백 후 남은 연사 시간 내 재개를 자동 검사합니다.
- 16개 GIF의 프레임 수 130장, 총 재생 시간 6,500ms, 무한 반복 설정을 검사합니다.
- `overview.png`는 12안의 정지 비교표입니다. 동작의 차이는 GIF에서 확인합니다.
