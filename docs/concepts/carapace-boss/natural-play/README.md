- Unity 6000.6.2f1, 실제 `GameCreateProject` 씬, 일반 몬스터·고블린·장애물·상자 유지.

- Editor 전용 `CarapaceNaturalPlayCheck.Run`과 `CarapaceNaturalPilot`을 추가했습니다. **종료 시 에디터를 닫으므로 반드시 별도 검증 프로젝트에서 실행**합니다.
