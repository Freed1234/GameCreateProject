# C·Shift 그래픽 재시안 5종씩

2026-11-17. **Z-A 깃바람 화살**, **X-B 나뭇잎 회오리**는 선택 완료입니다.
C1의 단일 대형 관통·양옆 밀치기, Shift1의 돌진 중 경로 타격을 유지하며 그래픽만 새로 비교합니다.
실제 프로젝트의 궁수·슬라임 이미지를 활용한 별도 시뮬레이션이며 **Unity 적용 영상이 아닙니다**.

## 비교 조건과 검증

- 비교 GIF는 1200×560, 3열×2행입니다. 위 행 R1·R2·R3, 아래 행 R4·R5·확정 스타일 기준입니다.
- 개별 GIF 10개는 800×560입니다. 모든 영상은 130프레임, 20fps, 6.5초, 무한 반복입니다.
- 후보별 위치·체력·타격·밀치기는 동일한 스냅샷을 공유합니다. SHA-256을 이전 그래픽 시안의 기록과 대조하여 C/Shift 동작이 바뀌지 않았음을 검사했습니다.
- 12개 GIF를 다시 읽어 프레임 수·재생 시간·반복 설정을 검사했습니다. `verification.json`에 결과를 저장했습니다.
- 정지 비교표에서 후보 이름과 효과 형태, 캐릭터 가독성, 확정 스타일 참조칸을 확인했습니다.
- 기존 GIF와 게임 코드·씬·프리팹·에셋은 수정하지 않았습니다. Unity 내 실제 판정·합성·성능은 이번 검증 범위가 아닙니다.

재생성: Pillow와 Windows 맑은 고딕을 사용할 수 있는 Python으로 이 폴더의 `generate.py`를 실행합니다. 상위 두 시안 생성 모듈과 기존 `verification.json`을 읽어 재사용합니다.

선택은 **C-R번호 / Shift-R번호**로 구분합니다.
