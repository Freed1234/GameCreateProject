# 황금갑각 실제 전투

> 최신 변경: 그림자·걷기·대기 모션을 추가했고, 사용자 요청으로 증강 선택은 비활성화했습니다. 스탯 시스템은 추가하지 않았습니다. [구현·검증](locomotion-v1/README.md). 아래 증강 관련 기록은 이전 상태입니다.

2026-11-20. 사용자가 선택한 5분 보스 교체입니다. 기존 시연 씬은 별도로 유지합니다.

## 연결

- 게임 씬 `GameCreateProject.unity`에 `BossDirector`, `MobHealthBars`, `GameClear`가 있는 `BossSystem`을 추가했습니다. 기존에는 코드만 존재하고 씬에 연결되어 있지 않았습니다.
- 첫 `BossTier`에 `goldenCarapace`를 지정했습니다. 기존 보스 체력·피격 프록시·UI·경험치·증강 보상 흐름을 재사용하고, 애니메이션과 공격은 `CarapaceCombat`이 담당합니다. 후속 보스는 앞 보스가 살아 있으면 기다립니다.
- 초기값은 체력 250 / 이동 1.6 / 공격 피해 2 / 회복 뒤 공격 간격 3초 / 경험치 10입니다. 같은 패턴을 연속 선택하지 않습니다. 플레이어와 8유닛 안에서 공격을 시작합니다.
- 몸통 접촉 피해는 끕니다. 피해는 예고된 세 스킬에서만 발생합니다. 예고 방향은 차징 시작에 잠깁니다.

## 범위와 시간

| 공격 | 준비/발동 | 판정 | 회복 |
| --- | --- | --- | --- |
| 돌진 | 준비 0.9초, 이동 최대 0.6초 | 폭 1.1, 중심 이동 6, 앞뒤 0.55를 포함한 직사각형 | 1.2초 |
| 강타 | 준비 0.7초 + 내려치기 0.15초 | 전방 100도, 반경 3.4 부채꼴, 타격 순간 1회 | 1초 |
| 등가시 | 준비 0.8초 + 발사 동작 0.075초 뒤 방출 | 발 위치 + Y 0.6에서 8방향, 폭 0.7, 중심 이동 8, 앞뒤 0.35 포함 | 발사 후 잔여 동작 0.075초 + 회복 1.35초 |

- `CarapaceGeometry`의 상수를 시연·실전 메시와 피해 코드가 공유합니다. `Indicator.shader`는 동일한 크기의 직사각형/부채꼴을 그립니다. 흰 선 자체의 렌더링 두께는 별도 0.045입니다.
- 플레이어의 Transform 위치를 피격점으로 사용합니다. 추가 플레이어 반경을 더하지 않으므로 시각 경계 밖에서 피해가 발생하지 않습니다.
- 돌진과 파편은 움직이는 정사각형과 플레이어의 프레임 간 상대 이동 구간을 교차 검사합니다. 전체 경로를 즉시 타격하거나 지나간 자리를 계속 타격하지 않습니다. 파편은 각 경로 끝까지 처리한 후 제거합니다.
- 돌진은 회전한 BoxCast로 장애물 앞에서 멈춥니다. 차징 시 예고 길이를 먼저 줄이고 이동 도중에도 재검사합니다. 강타와 등가시는 표시된 범위 전체에 피해를 주며 장애물로 별도 차단하지 않습니다.
- 한 스킬당 기하학적 접촉 시 한 번만 `PlayerHealth.TakeDamage`를 호출합니다. 무적으로 회피한 경우도 그 스킬에서 재피격시키지 않습니다. 등가시 중앙의 8중 교차도 1회입니다.
- 사망/비활성화/게임오버 시 예고와 잔여 파편을 정리합니다. 일시정지 중에는 애니메이션과 이동·피해가 멈춥니다.

## 검증 방법

별도 Unity 프로젝트에서 `-executeMethod CarapaceCombatCheck.Run`으로 실행합니다. 현재 작업 중인 에디터에서 실행하지 마세요. 검증 종료 시 에디터가 종료됩니다. 테스트는 실제 게임 씬을 열고 생존 시간을 300초로 설정해 자동 등장을 확인한 뒤, 다른 공격자를 제거한 통제 환경에서 경계/피해를 검증합니다.

초기 밸런스는 기존 5분 보스 수치를 계승한 값입니다. 장시간 실제 플레이 난이도 조정은 별도입니다.

## 체력바 수명 오류 수정 (2026-11-20)

`MobHealthBars.LateUpdate`가 같은 프레임의 캐시에 남은 삭제된 `EnemyHealth`에 `GetComponent`를 호출하여 `MissingReferenceException`을 일으키는 경로를 재현했습니다. 체력바 접근 전 Unity null·비활성화·사망 검사를 추가했습니다. 제외된 적의 기존 바는 기존 정리 루프에서 제거됩니다.

별도 Unity Play에서 `MobHealthBarsCheck.Run`으로 삭제/비활성화/사망 적 캐시, 후속 정상 적, 보스 프록시 제외를 검증했습니다. `MOB_HEALTH_BARS_LIFETIME_PASS`, 종료 코드 0. 로그: `Logs/MobHealthBars-20261120.log`.
## 적 참조 회귀 및 실제 씬 통합 검증 (2026-11-20)

- `WindRushDash`, `DarkSnipeSkill`에서 같은 프레임의 캐시에 남은 삭제된 적을 읽는 오류를 수정 전 각각 재현했습니다. 삭제/비활성화/사망 대상을 건너뛰고, 피해 전 위치를 저장해 이후 연출에 사용합니다. `FeatherDashSkill`도 피해 전 타격 위치를 저장합니다. 공유 캐시의 순회 중 변경은 하지 않습니다.
- `EnemyLifetimeCheck.Reproduce`는 수정 전 예외 확인용이고, 수정 후에는 `EnemyLifetimeCheck.Run`을 실행합니다. 실행 중 MissingReferenceException/NullReferenceException 로그는 실패로 처리합니다.
- 추가 검사: 조준 대기 중 적 삭제, 죽거나 비활성화된 적 건너뛰기, 살아 있는 대상 피해, 깃털 돌진 동시 처치, 일반 몬스터 생성/체력바를 켠 상태의 보스 세 패턴, 화면 밖 제거, 처치/보상/전투 재개/씬 재시작.
- 통합 검사에서 실제 씬에 `AugmentSystem` 및 선택 창이 없는 것을 발견했습니다. 기존 `GameUIBuilder`의 증강 UI 생성 코드를 재사용해 시스템·패널·카드 3개를 연결했습니다. 기존 HUD는 재생성하지 않았으며 기본 지급 흡혈은 꺼 두어 시작 능력치를 바꾸지 않았습니다. 재연결 메뉴는 `Tools > Game UI > Connect Boss Augment Rewards`이고 이미 연결되어 있으면 중복 생성하지 않습니다.
- 첫 연결 당시 증강 보상은 코드상 호출만 확인된 상태였습니다. 이번 검증에서 실제 선택 창 연결, 단일 보상 요청, 선택 후 시간 재개까지 확인했습니다.
- 실제 씬 검사에서 플레이어 체력만 높이고 자동 전직 안내를 억제했으며 생존 시간을 300초로 앞당겼습니다. 보스 패턴 순서는 검증 중 고정해 세 패턴을 모두 검사하고, 일반 몬스터는 계속 생성·처치했습니다. 이후 실제 `GameSession.Restart`를 호출했습니다. 장시간 수동 난이도 테스트를 대신하지는 않습니다.
