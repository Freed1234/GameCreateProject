# 궁수 2차 구현 · 2026.11.17

기존 `2026-11-17-unity-game.md`에 이어 읽는 최신 구현 기록입니다. 중간보스는 이번 범위에 포함하지 않았습니다. 이전 시안 및 미커밋 작업은 보존했습니다.

## 적용 상태

- 게임 씬 `Assets/Scenes/GameCreateProject.unity`에 컴포넌트·아이콘·30레벨 전직 목록을 연결하고 저장했습니다.
- 선택 확정: Z2/Z-A, X1/X-B, C1/C-R5, Shift1/Shift-R1.
- `SecondJobSystem`이 기존 4개 스킬을 끄고 새 4개 스킬을 켭니다. `JobAttackController` 재적용 시에도 기존 스킬이 다시 켜지지 않습니다.
- 전직을 보류하면 기존 스킬을 유지하며 다시 선택할 수 있습니다. 기본 자동 공격과 이동은 유지합니다.
- `SecondArcherSetup.Setup` 메뉴는 `Tools > Game UI > Setup Level 30 Second Archer`입니다. 현재 씬에는 이미 적용되어 있습니다.
- 리소스: `Assets/Resources/SecondArcher`의 Z/X/C/Shift/Hit 프레임, 조준 표시와 HUD 아이콘. 메타 파일과 참조를 함께 보존해야 합니다.

## 측정 결과와 한계

- 체력 30의 정지한 적 24마리를 동일한 두 원형 배치로 생성하고, 기본 자동 공격을 끈 상태에서 Z/X/C를 준비되는 대로 사용했습니다. 1차 12.933초, 2차 12.433초: **3.87% 단축**.
