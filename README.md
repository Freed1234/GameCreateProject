## Ver 0.5 (2026.10.07)

### 레벨 및 경험치
- 적 처치 시 경험치 1 획득.
- 1레벨 → 2레벨에 필요한 경험치: 5.
- 2레벨 이후 레벨업에 필요한 경험치: 매번 10.
- 화면 하단에 레벨과 경험치바 표시.
- 레벨업 후 남은 경험치는 다음 레벨로 이월.

### 전직
- 2레벨 달성 시 전직 선택창 표시.
- 전직 선택 중 게임 일시정지.
- 궁수 선택 가능.
- 전사는 준비 중으로 표시하며 선택 불가.
- 선택창을 닫은 경우 하단 버튼으로 다시 열기 가능.

### 직업별 공격
- 미전직: 짧은 사거리의 부채꼴 기본공격.
- 궁수 전직 후: 비관통 투사체 평타와 관통 스킬 사용.
- 평타는 0.5초 간격으로 자동 발사.
- 관통 스킬은 Z키로 사용하며 쿨타임은 5초.
- 관통탄은 적을 관통하며 카메라 밖으로 나가면 제거.
- 돌과 나무는 투사체를 차단.
- 직업별 공격 목록을 설정하여 공격 방식을 전환하는 구조 추가.

## Ver 0.3

### 청크 기반 맵 로딩
- 플레이어가 있는 청크와 주변 8개 청크를 불러오도록 구현.
- 이동에 따라 새로운 청크를 생성하고 멀어진 청크는 제거.
- 카메라에 보이는 영역이 청크 한 칸보다 작도록 크기 조절.

### 돌·나무 랜덤 배치
- 청크 안의 지정된 위치마다 나무·돌·없음 중 하나를 랜덤으로 선택.
- 생성 확률: 나무 30%, 돌 30%, 없음 40%.

### 장애물 충돌
- 돌과 나무의 충돌 영역을 이미지 형태에 맞게 조절.
- 나무의 잎 부분은 통과할 수 있고, 기둥 부분은 통과할 수 없도록 설정.
- 플레이어와 적이 장애물을 통과하지 못하도록 처리.

### 적의 장애물 우회 길찾기
- 적이 장애물에 막혀 멈추지 않고 우회하여 플레이어에게 접근하도록 구현.
- 여러 적이 경로 정보를 공유하도록 구성.
- 플레이어가 장애물에 붙었을 때 발생하던 과도한 경로 탐색 횟수를 줄여 최적화.

### 자동 공격의 가까운 적 우선순위 강화
- 공격 방향을 결정할 때 가까운 적에 더 큰 가중치를 부여.
- 가까운 적을 우선하는 정도를 설정값으로 조절할 수 있도록 구현.

### 맵, 장애물 이미지와 표시 순서
- 나무 이미지를 본체와 그림자로 분리.
- 나무의 잎 부분이 캐릭터 앞에 표시되도록 구성.
- 그림자는 캐릭터 아래에, 나무 본체는 위에 표시하도록 구성.
- 해당 버전 기준으로 실제 프로젝트 적용은 미완료.
