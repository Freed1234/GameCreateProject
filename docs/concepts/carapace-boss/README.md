# 황금갑각 돌격대장 동작 시연

선택한 동작: D-C1 낮은 뿔 돌진 / S-C2 양 주먹 내려찍기 / V-C2 압축 후 갑각 방출.

## 실행

- Unity에서 `Assets/Scenes/CarapaceDemo.unity`를 열고 Play합니다.
- 세 공격을 자동 반복합니다. R로 시작 상태를 다시 재생합니다.
- 정상 게임 씬과 기존 임시 보스 코드는 유지했습니다. 이 씬은 피해·체력·보상 없는 시각 시연입니다.
- 재생성 메뉴는 `Tools > Game UI > Create Carapace Demo Scene`입니다. 원본 게임 씬을 바탕으로 시연 씬과 프레임을 다시 만듭니다.
- 배치 검증은 **별도 검증 프로젝트**에서 `CarapaceDemoCheck.Run`을 호출합니다. 검증이 끝나면 에디터를 종료하므로 작업 중인 에디터에서 호출하지 않습니다.

## 타임라인

| 동작 | 준비 | 발동 | 회복 |
| --- | --- | --- | --- |
| D-C1 | 0.9초 | 6유닛/0.6초 돌진, 장애물 앞에서 정지 | 1.2초 |
| S-C2 | 0.7초 | 0.15초 내려치기 뒤 돌판 효과 1회 | 1초 |
| V-C2 | 0.8초 | 0.15초, 8방향 갑각 파편 동시 발사 | 1.35초 |

동작 사이 대기는 1초이며 반복 전 휴식 1초가 추가됩니다. 파편 속도는 초당 6유닛, 이동 거리는 8유닛입니다. 시연의 파편과 돌판은 피해 판정이 없습니다.

## 에셋과 생성 방식

- 원본 투명 시트: `Assets/Art/BossPreview/{Charge,Slam,Volley,Effects}.png`.
- Unity용 8프레임씩: `Assets/Resources/CarapaceDemo/`.
- 기본 제공 imagegen으로 선택한 동작 시트를 참고해 캐릭터만 투명 배경에 재생성했습니다. 준비→공격→회복의 8자세, 4×2 배치, 청색 몸체·금색 갑각·우측 방향을 지정하고 배경·문자·예고선·파편을 제외했습니다.
- 프레임 분리와 발 기준 정렬은 Unity 에디터에서 처리합니다. 첫 대기 자세 높이를 2.8유닛으로 맞추고 각 클립 내 배율을 유지합니다. Point 필터와 무압축을 사용합니다.
- 돌판·갑각 파편·흙먼지도 기본 제공 imagegen으로 별도 투명 이미지로 생성한 뒤 `Effects` 리소스로 분리했습니다. 예고선은 Unity 메시이며 효과 이동·생성 시점은 런타임에서 처리합니다. 모든 그래픽은 시연용이며 정식 전투 프리팹은 아닙니다.

## 캡처

`applied/CarapaceDemo.mp4`는 Unity 카메라를 30fps로 캡처한 전체 시연입니다. `Charge.gif`, `Slam.gif`, `Volley.gif`는 동일한 캡처를 스킬별로 나눈 약 15fps 미리보기입니다. GIF는 영상 인코딩을 위한 프레임 축소만 적용합니다. 재인코딩 스크립트는 `package_capture.py`입니다.

## 검증 결과

### 인디케이터 시안 v1

- 흰 외곽선은 고정하고, 빨간색은 색·불투명도를 유지한 채 중앙선에서 양옆으로 넓어집니다. 강타는 중앙 방향을 기준으로 부채꼴 각도가 넓어집니다.
- 돌진: 몸체 반경 0.55를 6유닛 이동한 캡슐 범위. 장애물이 있으면 미리 이동 가능 거리를 계산해 예고를 줄입니다.
- 강타: 반경 3.4, 전방 100도 부채꼴. 내려치는 동작까지 가득 찬 예고를 유지하고 타격 순간 끕니다.
- 등가시: 실제 파편 생성점인 보스 발 위치 + Y 0.6에서 시작하는 8개 직선 경로. 비행 거리 8, 시안의 파편 판정 반경 0.35(폭 0.7)로 가정했습니다. 기존의 짧은 4.2유닛 부채꼴 예고를 대체합니다.
- 이동·파편 생성·표시는 같은 기하 상수를 사용합니다. `CapsuleContains`와 `SlamContains`는 이 범위의 점 포함 판정을 제공합니다. **보스의 플레이어 피해는 아직 연결하지 않았으므로 실제 전투 판정 검증을 완료한 것은 아닙니다.**
- `indicator-v1/`에 별도 Unity 캡처와 GIF를 저장합니다. 이전 `applied/` 자료는 원래 금색 예고 시연을 보존합니다. 배치 검증 진입점은 `CarapaceDemoCheck.RunIndicators`입니다.
- Unity 실행에서 돌진 폭 경계, 강타 반경·각도 경계, 파편 전체 거리와 끝 반경, 장애물로 줄어든 예고와 실제 이동 거리 일치를 검사했고 기존 동작 검사도 통과했습니다. `Logs/CarapaceIndicators-20261120.log`의 `CARAPACE_DEMO_PLAY_PASS`와 종료 코드 0을 확인했습니다. 세 스킬의 차징 프레임을 직접 확인했습니다.

Unity 6000.6.2f1 별도 프로젝트에서 `CARAPACE_DEMO_PLAY_PASS`, 종료 코드 0을 확인했습니다. 24개 캐릭터 프레임 재생, 6유닛 돌진, 돌판 효과 1회, 파편 8개 동시 발사 및 제거, 예고 표시 동기화, 일시정지 시 자세·위치 고정, 벽 앞 돌진 정지와 후딜 진입, 재시작 시 상태 정리, MP4 인코딩 검사를 통과했습니다. 실제 캡처의 돌진·강타·파편 프레임을 시각 확인했습니다.

검증 로그: `Logs/CarapaceDemo-20261120.log`. 기존 Unity Editor Search 초기화 예외는 로그에 남아 있으나 시연 컴파일·실행 검사는 통과했습니다. 캡처는 자동 재생 시연이며 정식 전투 플레이 테스트는 아닙니다.

### 인디케이터 시안 v2 — 직사각형과 50% 투명도

- 돌진과 등가시의 둥근 끝을 직각으로 바꿨습니다. 기존 전체 길이와 폭(돌진 1.1, 등가시 0.7)은 유지합니다.
- 모든 스킬의 빨간 차징 표시 알파는 0.5이며 흰 외곽선과 중앙에서 넓어지는 방식은 유지합니다. 강타는 기존 부채꼴입니다.
- 등가시는 8개 직사각형의 합집합을 한 번만 그려 중앙 중첩부도 같은 투명도로 표시합니다.
- 이동과 장애물 충돌은 기존대로입니다. 직사각형 모서리는 이전 캡슐을 감싸는 보수적 예고이며, 플레이어 피해 판정은 아직 연결하지 않았습니다.
- 새 캡처는 `indicator-v2/`에 저장합니다. 이전 영상은 보존합니다. 별도 프로젝트 배치 실행은 `CarapaceDemoCheck.RunRectIndicators`입니다.
- Unity 검증 통과(종료 코드 0): 직사각형 모서리 픽셀, 범위 밖 투명 픽셀, 빨간 채움 알파 0.5, 등가시 중앙/팔의 동일 알파, 기존 24프레임·이동·발사·장애물 검사. 세 스킬의 실제 캡처도 시각 확인했습니다. 로그: Logs/CarapaceRectangle-20261120.log.
